# GC Odontologia — site institucional

Site responsivo estático, em HTML, CSS e JavaScript. Projetado para abrir no celular e computador.

## Incluído
- Página inicial e apresentação institucional
- Seção de categorias de tratamentos (confirmar serviços reais antes de publicar)
- Trechos de avaliações fornecidas pelo cliente
- Formulário de solicitação de horário que prepara uma mensagem no WhatsApp
- Botões para WhatsApp, telefone e Google Maps
- Aviso de privacidade inicial
- Layout adaptado para dispositivos móveis

## Testar localmente
Abra `index.html` no navegador. O formulário depende do WhatsApp/WhatsApp Web para enviar a solicitação.

## Publicar gratuitamente
### Opção A — Netlify Drop
1. Extraia o ZIP.
2. Abra https://app.netlify.com/drop no navegador e entre/crie sua conta.
3. Envie a pasta que contém `index.html`, `styles.css`, `script.js` e `privacidade.html` (ou arraste a pasta para a área de publicação).
4. Aguarde o link gerado e abra-o no celular para testar.

### Opção B — GitHub Pages
1. Crie um repositório no https://github.com/.
2. Envie os quatro arquivos do site para a raiz do repositório.
3. Em Settings → Pages, habilite a publicação a partir da branch principal e da pasta raiz.
4. Aguarde a URL exibida pelo GitHub Pages.

## Antes de publicar
- Confirme que a clínica autorizou o site, a marca e os dados de contato.
- Confirme o endereço, telefone, horário de funcionamento e lista de tratamentos.
- Confirme autorização para exibir nomes e trechos de avaliações de clientes.
- Troque os trechos de avaliações por links diretos para avaliações públicas se preferir evitar republicar conteúdo.
- Revise o aviso de privacidade e publique os contatos oficiais exigidos.
- Confirme se a clínica possui registro e identificação profissional que devam constar no site, e valide o conteúdo com o responsável técnico.
- A nota 5,0 e 172 avaliações foram vistas em uma captura enviada e podem mudar. Não são atualizadas automaticamente.
- Este projeto não possui painel administrativo, banco de dados, agenda sincronizada nem integração com prontuário. O pedido de horário é enviado manualmente via WhatsApp; a equipe precisa confirmar a consulta.
- O formulário não salva os dados no próprio site. Após abrir o WhatsApp, a pessoa ainda precisa revisar e enviar a mensagem.
- O mapa é um link para o Google Maps, não um mapa incorporado.
